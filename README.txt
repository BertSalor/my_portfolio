# Bert Conrad Salor — Portfolio

## Files
- `index.html` — page structure and content
- `style.css` — all page styling and responsive layouts
- `script.js` — navigation, theme toggle, animations, sliders, music control, and contact form
- `images/` — portfolio photos, project previews, and certificate files
- `music/` — background music

## Run locally
1. Extract the ZIP file.
2. Keep `index.html`, `style.css`, `script.js`, `images/`, and `music/` in the same project folder structure.
3. Open `index.html` in a browser. For best results, use VS Code with the Live Server extension.

## Important
- The Download CV button points to `my-cv.pdf`, but that file was not included in the uploaded ZIP. Add your actual CV PDF to this folder and name it `my-cv.pdf` for the button to work.
- The contact form opens the visitor's default email application using `bertconrads@gmail.com`. It does not send messages through a server.
- Background music starts only after the visitor clicks the music button because browsers restrict autoplay.
- External fonts and Font Awesome require an internet connection.
